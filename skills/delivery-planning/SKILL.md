# Delivery Planning

Produce a plan that a team can estimate, assign, and use to make decisions.

- Establish the goal, constraints, assumptions, scope, and non-goals.
- Decompose work by independently verifiable outcomes, not by document
  sections or generic phases.
- Make dependencies and the critical path explicit.
- Give every workstream an owner profile, inputs, tasks, and exit criteria.
- Define milestones by observable state changes.
- Include product, technical, operational, adoption, security, and cost risks
  only when relevant.
- Identify decisions still required and concrete first actions.

Do not invent deadlines, staffing, budgets, or organizational commitments.
Mark missing facts as decisions or assumptions.
