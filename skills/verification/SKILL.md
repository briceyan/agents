# Verification

Use this skill before reporting completion.

Workflow:
1. Select checks that match the change risk and project conventions.
2. Run static checks, unit tests, or focused integration tests as appropriate.
3. If a check fails, inspect the failure and fix task-related causes.
4. If a check cannot run, report the command and concrete blocker.
5. Summarize validation with exact commands and results.

Do not claim a change is verified unless the relevant command actually passed.
