# Review

Use this skill for code review.

Focus on:
- correctness bugs
- behavioral regressions
- security or data-loss risks
- missing tests for changed behavior
- maintainability issues that affect future work

Report findings first, ordered by severity. Include precise file and line
references when available. Keep summaries secondary and avoid listing issues
that are purely stylistic unless they block clarity or correctness.
