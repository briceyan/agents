# Git Workflow

Use this skill for source-control operations.

Workflow:
1. Inspect `git status` and separate task changes from unrelated user changes.
2. Use semantic commit messages.
3. Stage only files that belong to the task.
4. Run project-required checks before committing when available.
5. Push the current branch and open a ready pull request unless a draft is requested.

Never use destructive git commands unless the user explicitly asks for them.
